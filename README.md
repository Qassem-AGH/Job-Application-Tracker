# 💼 Job Application Manager

## Projektbeskrivning

Detta är ett C#-konsolprogram som hjälper användaren att hantera sina jobbansökningar. 
Programmet erbjuder en interaktiv meny där man kan:

- Lägga till nya ansökningar
- Visa alla ansökningar
- Filtrera efter status
- Sortera efter datum
- Visa statistik
- Uppdatera status
- Ta bort en ansökan
- Avsluta programmet med en dekorativ avslutningslogo

Programmet är designat med färgkodning och tydlig struktur för att vara användarvänligt och pedagogiskt.

---

## ▶️ Hur man kör programmet

1. Klona projektet från GitHub:
    
   git clone https://github.com/Qassem-AGH/Job-Application-Tracker.git
 
2- Öppna projektet i Visual Studio 

3- Kör programmet:
  - I Visual Studio: Tryck F5

4- Navigera i menyn genom att skriva en siffra (1–8) och tryck Enter

5- Följ instruktionerna i konsolen för att hantera dina jobbansökningar

## Reflektion
- Hur hjälpte LINQ dig att skriva renare kod?

  Jag använde LINQ för att filtrera och sortera listor av ansökningar på ett mer koncist och läsbart sätt. 
  Det gjorde koden enklare att förstå och underhålla.


- Vilken del av projektet var mest utmanande, och hur löste du den?

  Den mest utmanande delen var att implement era den interaktiva menyn och hantera användarinput på ett robust sätt.
  Jag löste det genom att använda en loop med switch-satser för att hantera olika menyval och validera användarinput noggrant.
